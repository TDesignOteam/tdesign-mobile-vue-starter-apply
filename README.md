# TDesign 移动端活动报名页面模板

## 项目介绍

tdesign-mobile-vue-starter-apply 是一个基于 TDesign Mobile Vue 组件库开发的移动端活动报名系统模板。本项目使用 Vue3、Vite、TypeScript 等现代前端技术栈构建，提供完整的活动报名流程和用户体验。

## 功能特性

- **首页模块**：热门活动推荐、活动列表展示、城市/地区筛选
- **活动详情**：活动信息展示、价格选择、分享功能
- **我的模块**：个人信息管理、已报名活动列表
- **订单流程**：购买确认、支付流程、购买结果展示
- **其他功能**：响应式设计、多语言支持、主题定制

## 快速开始

### 环境准备

- Node.js >= 16
- npm >= 7 或 yarn >= 1.22

### 安装依赖

```bash
npm install
# 或
yarn
```

### 开发

```bash
npm run dev
# 或
yarn dev
```

### 构建

```bash
npm run build
# 或
yarn build
```

## 项目结构

```
├── mock/                # 模拟数据
├── public/              # 静态资源

│   ├── hooks/           # 自定义Hooks

│   ├── locales/         # 国际化资源
│   ├── pages/           # 页面组件
│   ├── router/          # 路由配置
│   ├── store/           # 状态管理
│   ├── style/           # 全局样式
│   ├── types/           # 类型定义
│   ├── utils/           # 工具函数
│   ├── App.vue          # 根组件
│   └── main.ts          # 入口文件
├── .env                 # 环境变量
├── index.html
├── tsconfig.json        # TypeScript配置
└── vite.config.ts       # Vite配置
```
